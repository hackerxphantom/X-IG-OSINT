📥 Installation (Termux/Linux/macOS)

1. Update packages
```
pkg update && pkg upgrade -y
```
2. Install dependencies
```
pkg install python git -y
pip install requests rich colorama
```
3. Clone the tool
```
git clone https://github.com/hackerxphantom/X-IG-OSINT
cd X-IG-OSINT
```
4. Requirements Install
```
bash install.sh
```
5. Run the tool
```
python X-IG-OSINT.py
```
